# GALAXAI — Custom CNN V2
## Deep Learning-Based Multi-Attribute Galaxy Morphology Analysis

---

## 1. Project Objective

GALAXAI is a deep learning system designed to automatically analyze multiple morphological attributes of galaxies from Hubble Space Telescope images.

Instead of treating galaxy morphology as a single classification problem, the system formulates it as a **multi-task learning problem**.

The model learns 10 morphology-related tasks simultaneously:

1. Smooth / Featured
2. Edge-on
3. Bar
4. Spiral Arms
5. Bulge Prominence
6. Roundedness
7. Disturbed
8. Merger
9. Clumpy Appearance
10. Galaxy Symmetry

The first architecture developed for the project is:

> **GALAXAI Custom CNN V2**

The same dataset split and task definitions will later be used for comparison with ResNet and MobileNet.

# 2. Dataset

## Galaxy Zoo: Hubble

The project uses the **Galaxy Zoo: Hubble (GZH)** dataset.

The local dataset contains:

- 80,632 galaxy images
- Hubble Space Telescope observations
- Galaxy morphology annotations
- Multiple morphology questions arranged as a hierarchical decision tree

        Our first model is a custom multi-task convolutional neural network. The input is a 224 by 224 RGB galaxy image. The CNN contains four convolutional blocks, where the number of feature channels increases from 32 to 256 while spatial resolution decreases from 224 by 224 to 14 by 14. Each block uses two 3 by 3 convolutions with batch normalization and ReLU activation followed by max pooling. After the convolutional feature extractor, adaptive average pooling produces a compact 256-dimensional representation. This passes through a 256-unit fully connected layer with ReLU and 40 percent dropout. The shared representation then branches into ten task-specific heads: eight binary morphology heads, one four-class Bulge head, and one three-class Roundedness head. Thus, the model performs multi-task learning with ten morphology tasks and fifteen output logits. Task-specific masks handle the hierarchical nature of the Galaxy Zoo: Hubble annotations, and class weighting is used to address the strong imbalance in rare morphology attributes
