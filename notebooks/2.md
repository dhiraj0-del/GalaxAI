# GALAXAI — Custom CNN V2
## Deep Learning-Based Multi-Attribute Galaxy Morphology Analysis

---

## 1. Project Objective

GALAXAI is a deep learning system designed to automatically analyze multiple morphological attributes of galaxies from Hubble Space Telescope images.

Instead of treating galaxy morphology as a single classification problem, the system formulates it as a **multi-task learning problem**.

The model learns 10 morphology-related tasks simultaneously:

1. Smooth / Featured
2. Edge-on
3. Bar
4. Spiral Arms
5. Bulge Prominence
6. Roundedness
7. Disturbed
8. Merger
9. Clumpy Appearance
10. Galaxy Symmetry

The first architecture developed for the project is:

> **GALAXAI Custom CNN V2**

The same dataset split and task definitions will later be used for comparison with ResNet and MobileNet.

# 2. Dataset

## Galaxy Zoo: Hubble

The project uses the **Galaxy Zoo: Hubble (GZH)** dataset.

The local dataset contains:

- 80,632 galaxy images
- Hubble Space Telescope observations
- Galaxy morphology annotations
- Multiple morphology questions arranged as a hierarchical decision tree
